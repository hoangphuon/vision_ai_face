# Vision AI - Phát hiện khuôn mặt (Face Detection)

Đây là một chương trình Python đơn giản sử dụng thư viện OpenCV để phát hiện khuôn mặt trong thời gian thực thông qua Webcam.

## Tính năng
- Nhận diện khuôn mặt thời gian thực.
- **Phân tích biểu cảm (Emotion Recognition)**: Vui, Buồn, Bình thường, Ngạc nhiên, v.v.
- Tự động tải mô hình AI cần thiết.

## Yêu cầu hệ thống
- Python 3.x
- Webcam hoạt động bình thường.

## Cài đặt và Chạy
1. Cài đặt các thư viện cần thiết:
   ```bash
   pip install -r requirements.txt
   ```

2. Chạy chương trình:
   ```bash
   python main.py
   ```

3. Nhấn phím **'q'** trên cửa sổ hiển thị để thoát.
